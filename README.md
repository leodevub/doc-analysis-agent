# Docvyn — Intelligent Document Analysis Agent

AI-powered agent that analyzes CSV and PDF files and answers questions in any language.

**Live Demo:** https://docvyn-ui.onrender.com  
**API Docs:** https://docvyn-api2.onrender.com/docs

## What it does

- Upload a **PDF** and ask questions — the agent uses RAG to find the answer
- Upload a **CSV** and ask questions — the agent analyzes the data
- Ask in any language — the agent responds in the same language

## Tech Stack

LangGraph · FastAPI · ChromaDB · RAG · Groq · Streamlit · Docker · JWT
